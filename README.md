# 関西・全国 能楽公演ガイド

日本全国、特に関西（大阪・京都・兵庫・奈良・滋賀・和歌山）で行われる「能・狂言」の公演情報をWebから自動収集し、PCやiPhoneで見やすく一覧・検索できるまとめサイトです。

## 主な特徴
- **関西メイン＋全国切り替え**：開いた瞬間は「関西すべて」を表示。大阪・京都・兵庫・全国へワンタップで切り替えできます。
- **11の情報源から自動収集**：大槻能楽堂、山本能楽堂、朝陽会館、京都観世会館、金剛能楽堂、大江能楽堂、西宮能楽堂、湊川神社 神能殿、大津市伝統芸能会館、公益社団法人 能楽協会、能暦から最新予定をまとめて取得します。
- **iPhoneで見やすい操作性**：画面下部のタブバー（一覧 / カレンダー / お気に入り）、横スクロールできるエリアボタン、下から開く詳細シートを備えています。
- **追加インストール不要**：Python 3 の標準機能と HTML / CSS / JavaScript のみで動作します。

## 使い方

### 1. 最新の公演情報を集める（更新する）
以下のいずれかの方法で最新データを取得できます。
- フォルダ内の **`update.bat`** をダブルクリックする
- または、PowerShell / コマンドプロンプトで次を実行する：
  ```powershell
  python scraper.py
  ```

### 2. PCで見る
- フォルダ内の **`index.html`** をダブルクリックするだけで、ブラウザが開いて閲覧できます。

### 3. iPhoneで見る（同じWi-Fi内）
1. PCで次のコマンドを実行して簡易サーバーを起動します：
   ```powershell
   python server.py
   ```
2. 画面に表示される **`iPhoneで開く : http://192.168.x.x:8000/`** のURLを、同じWi-FiにつないだiPhoneのSafariで開きます。
3. Safari下部の「共有」ボタン → **「ホーム画面に追加」** を押すと、アプリのようにワンタップで開けます。

> **ヒント**：Windowsファイアウォールの許可画面が出た場合は「プライベートネットワーク」へのアクセスを許可してください。

## ファイル構成
- `scraper.py`：公式サイト等から公演情報を収集するスクリプト
- `data/performances.json` / `data/performances.js`：収集された公演データ
- `index.html` / `style.css` / `app.js`：Webサイト本体
- `server.py`：PC・iPhone閲覧用の簡易Webサーバー
- `update.bat`：ワンクリック更新用バッチファイル
